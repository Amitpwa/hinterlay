# Hinterlay: project context (read this first)

Android photo editor: finds the subject on-device and puts text **behind** it. Also camera with filters and
face masks, crop, skin smoothing, photo adjustments, WhatsApp stickers, 3D tilt live wallpaper, "Do magic"
AI suggestions, widgets/shortcuts/lock-screen camera. Owner: ashutosh.pandey@amzbizsol.in (solo developer,
Windows 11, PowerShell). Free app, AdMob + tips + $100 lifetime ad-free purchase.

User preferences that matter: black-and-white **minimal** UI everywhere, **no purple, no hard shadows**,
subtle motion and sound, "futuristic but clean", everything stored locally, privacy first. Wants plain,
honest status reports: say what was verified and what was not.

- Screenshots: `adb shell screencap -p /sdcard/Download/x.png`, pull, delete (do not leave screenshots in /sdcard/Pictures: they pollute the photo picker).
- Camera on the emulator is a fake test scene (no face), so masks cannot be judged there.

## Tool gotchas in this environment

- The shell safety filter sometimes blocks long PowerShell commands that mix `Remove-Item`-like patterns; if "Remove-Item on system path ... is blocked" appears, split the command or use the Edit/Write tools.
- In PowerShell `r` is an alias (Invoke-History): do not name helper functions `r`; helper `rep` worked.
- After `cd` into a subfolder, `.\gradlew.bat` is not found: run it from the project root.
- Android resource strings need `\'` for apostrophes. Read/Write files as UTF-8 without BOM.
- Background builds report "failed" when a trailing command returns exit code 255: check the log for `BUILD SUCCESSFUL`.

## Design decisions to keep

- Theme: fixed black/white `MaterialTheme` (follows system light/dark), error red only for destructive. No wallpaper colours, no accent colour, no elevation shadows. Decorative halftone dots at about 7% opacity behind tabs and in the nav bar. Nav bar: floating rounded bar, sliding black pill, raised camera disc with a quiet pulse.
- Erase: text erase uses a per-layer mask; **subject erase** uses a low-res mask plus `SubjectPlate` (diffused background fill) so the removed part truly disappears. Tilt wallpaper back plane = softly blurred photo with the subject area replaced by hard-blurred fill; sharp subject on the front plane.
- Crop/Smooth/Do magic buttons live on the canvas (not in the scrolling tool tabs) by user request; no more tabs should be added to the bottom panel.
- Editor panel is resizable by dragging the handle; max height 42% of screen.
- Ads: rewarded ad on Export, banner on export progress, **no start-of-session interstitial**. Referral reward is local only (once per 24h), not verified.
- Notifications are asked after the first export, never at launch. Usage analytics are opt-out in More.
